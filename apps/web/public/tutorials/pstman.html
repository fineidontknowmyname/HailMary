Section 01

Setup & UI Orientation

Install Postman, navigate the interface, and set up your first Collection to organize your API requests like a pro.

1
Download & Install
Head to postman.com and download the desktop app. You can also use the browser version. On the sign-in screen, click "Skip and go to app" — you don't need an account to use the core features.
2
Create a Workspace
Workspaces are top-level containers. Use the default "My Workspace" for personal projects. For team projects, create a shared workspace.
Section 02

HTTP Requests — GET, POST, PATCH, DELETE

The four main HTTP methods you'll use daily. Try changing the method below and sending a live request to our test API.

📥
GET  Fetch Data
Retrieves data from the server. No request body needed.
📤
POST  Send Data
Sends a JSON payload to create something new.

Variables — Stop Hardcoding Everything

  
Variables make your collections dynamic. In this sandbox, we've pre-configured {{baseUrl}} and {{$randomInt}}. Notice how the URL resolves dynamically when you click Send.


  
  

    

      
      
      
    

    

      

        

        

      

      

    

  


  
Built-in Dynamic Variables

  

    

      

      
{{$randomEmail}}

      
Generates a random email like jane.doe@example.com on every request.

    

    

      

      
{{$randomInt}}

      
Generates a random integer. In our sandbox above, it resolves to a number between 1 and 10 to fetch a random user.

    

  







  
Section 05

  
Authentication & Scripting

  
Most real APIs require authentication. You usually send a login request, capture the token using a script, and pass it in Headers.

  

    
Tests Tab — Auto-Capture Token

    
const response = pm.response.json();
pm.globals.set("accessToken", response.accessToken);
// Now use {{accessToken}} in any request's Auth tab
